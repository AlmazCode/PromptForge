# PromptForge — учебная версия

Небольшой сайт для практики написания промптов. Интерфейс на английском; пояснения к коду для защиты приведены ниже. Комментарии из исходников удалены по просьбе автора. Все девять основных страниц используют обычный HTML, готовые стили Bootstrap и jQuery 3.7.1. Разметка больше не перестраивается большим JavaScript-конструктором.

## Запуск

`npm start` → `http://127.0.0.1:3000`. Нужен Node.js 20 или новее; Python не требуется.

Нужен HTTP-сервер для ES-модулей: открытие через `file://` не поддерживается. Бэкенда, базы данных и запросов к AI нет. CDN jQuery подключён перед приложением; если CDN недоступен, загружается та же библиотека из `vendor/jquery/`.

## Что осталось

- 16 заданий с отдельными исходными данными, требованиями и подсказками.
- Каталог: поиск, категория, сложность, статус «проверено» и сортировка.
- Страница задания: черновик, счётчик, простая оценка по шести признакам и сохранение попытки. Практиковаться можно гостем.
- Учебные формы регистрации/входа, показ пароля и профиль с именем и email. Пароли проверяются и очищаются; они не сохраняются и не используются для настоящей авторизации.
- История попыток с просмотром/удалением и таблица лучших личных результатов.
- FAQ с анимацией и форма обратной связи с проверкой каждого поля. Сообщение никуда не отправляется и не сохраняется.

По выбору автора удалены курсы, сравнение попыток, квоты, подписки, достижения, редактор аватара, сложные настройки и переключение языков. Старые сценарии тестирования этих удалённых функций заменены проверками учебной версии.

## Карта JavaScript для защиты

Читать лучше в таком порядке:

| Файл | За что отвечает | Что объяснить |
| --- | --- | --- |
| `js/main.js` | Запуск и мобильное меню | Выбор модуля по `data-page`, обработчик `.on()` |
| `js/jquery-runtime.js` | Готовность jQuery | `$(function () {})`, CDN и локальная копия |
| `js/data.js` | Массив 16 заданий | Объекты и свойства; здесь нет алгоритма |
| `js/catalog.js` | Каталог | `filter()`, создание карточек, делегирование кнопок |
| `js/task.js` | Работа с заданием | Получение `id` из URL, события ввода/submit, результат |
| `js/logic.js` | Расчёты без DOM | `map()`, `filter()`, `reduce()`, веса критериев |
| `js/storage.js` | Данные браузера | `JSON.parse/stringify`, `localStorage`, обработка ошибки записи |
| `js/validation.js` | Правила проверки | Возвращает объект ошибок; регулярные выражения email/телефона |
| `js/forms.js` | Общая работа форм | `.val()`, `.find()`, `.each()`, ошибки рядом с полем, `preventDefault()` |
| `js/auth.js` | Регистрация и вход | Проверить → сохранить только имя/email → очистить форму |
| `js/password.js` | Показ пароля | `.siblings()`, `.attr('type')`, `$(this)` |
| `js/guide.js` | Обратная связь | Валидация, счётчик, успех только после проверки и сброс формы |
| `js/effects.js` | FAQ | `.slideToggle(duration, callback)` и доступность с клавиатуры |
| `js/jquery-ui.js` | Небольшие общие UI-функции | Безопасный `.text()`, `.fadeIn()`, `.fadeOut()`, классы |
| `js/profile.js` | Простой профиль | Вывод имени/email и количества попыток |
| `js/solutions.js` | История | Построение строк таблицы, делегированное удаление |
| `js/leaderboard.js` | Личные лучшие результаты | Одна лучшая попытка на задание; глобального рейтинга нет |

Рабочие JS-файлы ограничены 200 строками тестом. Это предел для читаемости, а не требование дробить каждую функцию на отдельный файл. Большинство модулей значительно короче.

`js/old-js-version.js` — только указатель на три старые native JS-реализации в `js/archive/`. Архив не подключён ни к одной странице, не исполняется и не нужен для понимания текущего приложения. Зависимости архивных функций отражают старую версию и не входят в учебную сборку.

## Как работает оценка

В `logic.js` шесть критериев: роль — 20%, формат — 25%, длина — 15%, пример — 20%, тон — 10%, действие — 10%. Каждый найденный английский ключевой признак получает 10, отсутствующий — 0. Итог: сумма `оценка × вес`, максимум 10.

Это объяснимый учебный алгоритм, а не AI-оценка качества. В текущей упрощённой версии нет ограничений на число проверок. Старые результаты и сохранённые оценки критериев остаются без пересчёта, даже если прежние правила расчёта отличались.

## Что показать по jQuery

Три переписанные функции находятся в `catalog.js`, `password.js` и `guide.js`. Селекторы по id, классу, тегу и атрибуту, фильтр `:not(:disabled)`, обход DOM, две цепочки методов, `$(this)`, `.on()` и делегирование используются в реальных обработчиках.

- `.text()` вставляет текст; `.html()` используется только для фиксированной разметки счётчика.
- `.attr('checked')` описывает исходный атрибут; `.prop('checked')` читает текущее состояние checkbox.
- Карточки создаются из массива через `.append()`/`.appendTo()` и управляются классами.
- `.fadeIn()`, `.fadeOut()` и `.slideToggle()` имеют длительность и callback. При системной настройке уменьшения движения длительность равна нулю.
- `required` сохранён; в реальном приложении проверка браузера не заменяет серверную проверку.

## Хранение и проверки

Новые записи находятся в `promptforge.study.v1`: `{ profile, attempts, drafts }`. Если нового ключа нет, сайт читает прежний `promptforge.frontend-demo.v1`. Старый ключ не изменяется и не удаляется. Ошибка хранилища показывается явно; ложного сообщения об успешном сохранении нет. Выход убирает выбранный профиль, но сохраняет историю устройства. Пароли и обратная связь не записываются.

`npm test` проверяет расчёты, формы, чтение прежних данных, ошибки хранения, импорты, размер модулей и подключение ресурсов. `npm run test:browser` проверяет учебные пользовательские сценарии и все основные страницы на мобильной и настольной ширине. Скриншоты находятся в игнорируемом каталоге `test-results/`.

## Совместимые исправления после обновления от 2026-11-08

- Перенесены проверка обязательного подтверждения пароля, сохранение ошибок остальных полей при исправлении одного, повторная проверка подтверждения при изменении пароля и защита формы от обычной GET-отправки до загрузки обработчиков.
- Параметр `next` сохраняет переход к заданию между формами входа/регистрации и в ссылке после успешной проверки. Разрешены только известные локальные страницы; внешние адреса заменяются ссылкой на профиль. Пароли по-прежнему не сохраняются, а формы остаются демонстрационными.
- Профиль показывает прочерк вместо отсутствующей средней оценки. Ограничения длины имени/email применяются из JavaScript.
- `.gitattributes` сохраняет исходные байты jQuery, чтобы переводы строк Windows не нарушали integrity-проверку. Полная MIT-лицензия находится в `vendor/jquery/LICENSE.txt`.
- `scripts/serve.mjs` только раздаёт статические файлы для локального просмотра и тестов на Windows/Linux. У приложения по-прежнему нет серверных аккаунтов, API и базы данных.

HTML и CSS при переносе не редактировались. Удалённые в `23628c1` достижения, настройки и серверная архитектура не возвращались. Первоначальные доработки прежней версии сохранены локально в ветке `codex/auth-profile-before-sync` (`d33e034`). Использование AI отражено в `AI-LOG.md`.

Проверка объединённой версии: `npm test` — 9 тестов; `npm run test:browser` — 12 сценариев, все прошли. На Windows проверено в установленном Google Chrome через `PLAYWRIGHT_CHROMIUM_EXECUTABLE`.
