01 / PROCESS

Evaluation process

AFTER SUBMISSION

Every prompt goes through six stages before you see the final score. The entire process takes 5–10 seconds.

01
SubmissionYou enter your prompt and click “Check”. The prompt is sent to the evaluation server.
02
ParsingThe system extracts structure: role, format, constraints, examples, tone.
03
ComparisonYour prompt is checked against reference examples using 4–6 independent criteria.
04
ScoringEach criterion is scored 0–10 independently. Criteria are never compared to each other.
05
AggregationScores are weighted and summed. The system runs 2–3 passes and takes the median to reduce noise.
06
ResultsYou see your score, per-criterion breakdown, and personalized tips on the task page.
02 / RUBRIC

Scoring criteria

WEIGHTED

Each solution is evaluated on 4–6 atomic criteria — independent yes/no checks. The final score is a weighted average of all criteria.

Evaluation rubric showing each criterion, what it checks, and example values.
Criterion What it checks Weight Example (good)
Role definedIs there an explicit role for the model?20%You are a data analyst
Output formatIs the response format specified?25%Format: numbered list
ConstraintsAre length or content limits set?15%no more than 150 words
ExamplesAre few-shot examples provided?20%Example: 1. Revenue grew 12%
ToneIs the communication style defined?10%Tone: professional, no filler
Task clarityIs the main task unambiguous?10%Write a brief summary

The same rubric is used on every task page. JS reads the data-criterion and data-weight attributes to calculate your final score.

03 / TERMS

Glossary

CORE CONCEPTS
Zero-shot
A prompt with no examples — just the task. On PromptForge, zero-shot prompts are the baseline difficulty level.
Few-shot
1–5 examples to guide the model’s output format and style. Tasks marked intermediate or advanced expect few-shot prompts.
CoT
Step-by-step reasoning inside the prompt. Improves accuracy on complex tasks. The evaluation system detects CoT by looking for sequential markers (first, then, therefore).
Temperature
Controls response diversity: 0 = deterministic, 1 = creative. Most PromptForge tasks are designed for temperature = 0.
System prompt
A hidden instruction that sets the model’s role, tone, and constraints. PromptForge tasks are evaluated against system-level instructions, not user-facing text.
04 / EXAMPLE

Prompt example

9.2 / 10

A quality prompt for “Sales data summarization”:

prompt.txt
SCORE 9.2 
You are a data analyst. Write a brief summary
of the sales table for September 2026.

Format: numbered list of 5 items.
Tone: professional, no filler.
Constraint: no more than 150 words.

Example:
1. Revenue grew 12% compared to August.
2. Top 3 products account for 60% of sales...

This prompt scores 9.2/10 because it includes a role, format, constraint, tone, and one example — all six criteria are satisfied.

05 / FAQ

Frequently asked

COMMON QUESTIONS
Can I submit a prompt multiple times?

Yes — improve and resubmit. All attempts are saved in your history. Your best score counts toward the leaderboard.

Which model is used for evaluation?

OpenAI and Anthropic LLMs. The target model is listed on each task page (e.g., “Target: GPT-4o”).

Why does the score differ on retry?

CoT judges vary slightly between runs. The system takes the median of 2–3 runs to reduce noise. If the difference exceeds 25%, the rubric is flagged for review.
