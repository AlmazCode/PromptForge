Evaluation Process

Every prompt goes through six stages before you see the final score.

01
Submission You enter the prompt text in the task form and click "Check". The prompt is sent to the server.
02
Parsing The system analyzes the prompt structure: role, output format, constraints, examples.
03
Comparison Your prompt is checked against reference examples using atomic criteria.
04
Scoring Each criterion is scored 0–10 independently. Criteria are not compared to each other.
05
Aggregation Scores are weighted and summed. The system runs 2–3 passes and takes the median.
06
Tips Personalized suggestions on what to improve and how.

How Scores Are Calculated

Each solution is evaluated on 4–6 atomic criteria — independent checks like "is there a role?" or "is the format specified?". Each is scored 0–10.

The final score is a weighted average. The system runs 2–3 evaluation passes and takes the median to reduce noise from the LLM judge.

Glossary

Zero-shot
No examples — just a task and a response. Simplest approach.
Few-shot
1–5 examples to guide the model's output format and style.
Chain-of-thought
Step-by-step reasoning. Improves accuracy on complex problems.
Temperature
0 = deterministic, 1 = creative. Controls response diversity.
System prompt
Hidden instruction setting role, tone, and constraints.

Prompt Example

A quality prompt for "Sales data summarization":

prompt.txt
You are a data analyst. Write a brief summary
of the sales table for September 2026.

Format: numbered list of 5 items.
Tone: professional, no filler.
Constraint: no more than 150 words.

Example:
1. Revenue grew 12% compared to August.
2. Top 3 products account for 60% of sales...

FAQ

Why did my prompt get a low score?

You may have missed the output format or the model's role. Check the tips after evaluation — they show which criteria scored low.

Can I submit a prompt multiple times?

Yes — improve and resubmit. All attempts are saved in history.

Which model is used for evaluation?

OpenAI and Anthropic LLMs. The target model is listed per task.

What are "atomic criteria"?

Separate yes/no checks: role present? format specified? length limited?

Why does the score differ on retry?

CoT judges vary slightly. The system takes the median of 2–3 runs.
